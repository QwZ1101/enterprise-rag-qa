## 数据和标注

唯一来源是本地《中芯国际2024年年度报告》PDF（222 页）。保持现有 738 个分块和 FAISS 索引不变。24 题：20 道有答案，其中 2 道刻意覆盖解析缺页；4 道材料不能回答。按章节选题，包含事实、跨年度数字、表格单位、知识产权、董事会等，不是随机抽样或独立隐藏测试集。不可回答题有 2 道未来实际数题，不能代表所有拒答难度。

`smic2024_pilot_v1.jsonl` 有题目、标准答案、单位、证据页、原始字段值、原文片段。页码是从 1 开始的 PDF 物理页码，与此 PDF 印刷页码一致。标注由 AI 辅助并核对原文和页面图像，**尚未由候选人或独立人员复核**。缺页题不会因为现有索引答不出就改成无答案题。

数据集、PDF、分块、FAISS 文件 SHA256 固定在 manifest。运行前验证，不符即停止。模型只收到题目及实际检索片段，不会收到标准答案、金标页码或评分规则。不要看过结果后修改本版标准答案；发现标注错误须记录勘误并另建版本、保留旧结果。

## 冻结的指标口径

- 自动严格匹配率：正确题数 / 全部 24 题。数字用 Decimal 比较，忽略千位逗号，不忽略数量级或单位；题中人民币金额要求元，按原文千元换算。字符串只接受冻结答案和别名；含正确词但带额外内容的回答留待复核。错误、异常、缺失都算未通过，不能从分母剔除。
- 可回答题正确数 / 20，以及不可回答题正确拒答数 / 4，分开报告。自动拒答仅接受结构化 `N/A`；自然语言拒答待复核。
- 指定证据页 Hit@1/5/10：前 k 个**分块**是否出现标注页；MRR@10 为首个标注页所在分块排名的倒数，未命中为 0。分母全部 20 道可回答题，包括缺页题。标注页非所有等价证据页的穷举，不称为完整 Recall 或语义检索准确率。
- 字段证据 Hit@10：前 10 个分块内，是否存在标注页且同一分块同时出现标注字段和值。用于比页码命中更严格的机械诊断，仍不等于语义相关性。
- 解析字段保留抽查：20 个指定页的字段和值共现数 / 20；不重新调用解析器。**不是完整 PDF 解析准确率**，不覆盖所有表格、公式、版式或行列关系。
- 回答复核：逐题查看 `final_answer`，判为正确 / 错误 / 无法判定 / 调用失败；单独核对它的全部事实性断言是否被本次检索上下文支持，记 supported / unsupported / uncertain / abstained / failed。正确答案但缺乏检索证据仍可为 unsupported，错误答案或未命中不能直接自动等同“幻觉”。复核由 AI 完成时必须保留此标识和待人工复核状态。
- 无依据回答率：unsupported / 所有正常完成且未拒答的回答（uncertain 保留在分母，并另报其数量）。仅针对最终回答，不扩展到未审查的推理摘要、内部推理或系统整体“幻觉率”。如有 uncertain 同时报上下界，不把不确定项算成已支持。
- 新增 BM25 基线：同一批 738 分块、同样问题、top10；中文连续片段二字切分，ASCII 单词/数字，BM25Okapi k1=1.5、b=0.75，同分按原分块顺序。只对比检索，**没有做 BM25 问答生成**。差值报百分点，不当作历史系统提升；无旧模型/新模型幻觉率对照。

## 运行

在项目根目录使用现有 Python 3.9 环境。基础依赖已在原项目中；离线检索需要 rank_bm25。

```powershell
python -m unittest discover -s tests -p test_evaluation.py -v
python -m evaluation.run_pilot offline --out evaluation/runs/local_check
# 仅在获得本批题目的外部发送授权后运行下面命令；不要自动重复执行。
python -m evaluation.run_pilot live --out evaluation/runs/live_20261021 --allow-external-24
```

live 使用原 QuestionsProcessor 路由、向量检索、提示词和答案处理，模型 qwen3.8-flash、embedding qwen3.7-text-embedding-flash；top10、不重排、不展开父页。为控制费用和等待，测试脚本将回答上限设为 2048 tokens、超时 60 秒、SDK 重试 0；向量超时 30 秒、SDK 重试 0。每题最多一次 embedding、两次生成（原有 JSON 修复最多一次），逐题串行。已用运行目录拒绝覆盖或自动续跑；失败保留，需要另行授权才可再次跑。

记录各题脱敏 trace、输入/检索结果/回答、API 请求 ID、时间、token 用量和文件摘要。详细分步推理字段不导出。结果目录不提交 Git。`completed` 仅代表代码执行完成；是否答对由评分和复核另行判定。

这是一个小样本、单文档、AI 辅助标注的诊断基线。不要外推为生产准确率、独立人工评测、全行业泛化能力或证明原简历数据。

## 本轮结果后的补充定位（不修改冻结规则）

实际发现：没有独立页条目不代表整页正文丢失。跨页表格可能被合并在前一页：例如PDF第44页的简历在解析43页，第118页流动负债表在解析117页。因此Q19、Q20称为页码缺项挑战题更准确。同页字段抽查18/20不能当成内容保留只有90%；这些字段在其他页仍可能存在。

Q20返回N/A，完整语料有正确数值，但本次top10未召回对应分块，归类为检索遗漏。Q03和Q24自动严格匹配失败而语义可接受，复核分数与自动分数并列保存，不修改金标或旧分数。AI复核文件需绑定预测文件SHA256，每题必须有标签和说明；支持性证据必须来自实际召回片段。

```powershell
# case_review.json必须先逐题审核填写，不能用这个命令自动猜判分。
python -m evaluation.review_report "实际运行结果目录"
```

排名评测概念可参见[Stanford 信息检索教材](https://nlp.stanford.edu/IR-book/html/htmledition/evaluation-of-ranked-retrieval-results-1.html)；本项目具体指标和分母以上文冻结规则为准。
